Selected work

Automation and AI workflows I've built inside paid media teams. Each one replaced a recurring manual process, and each one keeps a person in control of what actually changes in an account.

Scheduled AI search query analysis

In production

Search term analysis used to cost at least an hour per account, every week. This workflow runs on a schedule: it pulls search-term data through a Google Ads MCP integration, reads it against client-specific context documents, and returns negative keyword recommendations with a confidence score and a suggested list placement. Recommendations arrive in Slack, where a person approves them before anything is applied.

  • 8 client accounts
  • 8+ hrs/week manual analysis replaced
  • 1,000+ negatives supported per week
  • MCP
  • LLM analysis
  • Slack
  • Human-in-the-loop

Automated Google Ads audit framework

In production

A framework that runs 100+ checks across a Google Ads account, produces a detailed Excel breakdown, identifies the key findings and populates a templated pitch or review deck from them. A manual audit took a couple of hours of an analyst's time; the automated version produces a first draft in roughly twenty minutes.

  • 100+ account checks
  • 2+ hrs → ~20 min to first output
  • ~90% of proposal audits
  • Google Ads API
  • Excel reporting
  • Deck generation
  • New business

MCP-powered 12-month client reviews

In production

Annual performance reviews are valuable to clients and slow to build. This workflow asks the account manager a short set of strategic questions, retrieves the performance data it needs through a Google Ads MCP integration, and generates the full review deck in the background. The account manager then QAs the output rather than assembling it from scratch.

  • 2+ hrs → ~2 min active preparation
  • 4 of 4 PPC team members using it
  • MCP
  • Client reporting
  • Rollout & adoption

Merchant Center disapproval monitoring

In production

Product disapprovals quietly remove inventory from Shopping and Performance Max, and they are usually found late. This workflow runs daily across the highest-risk accounts, logs product approval status and posts a Slack alert when disapprovals appear. Built on a shared Merchant Center MCP integration, which I've also contributed code changes to.

  • ~30,000 products monitored
  • Daily scheduled checks
  • Slack disapproval alerts
  • Merchant Center
  • Feeds & Shopping
  • Scheduled jobs
  • Slack

Also building

Claude CLI

My own command-line interface for the Claude API, with reusable personality and pre-prompt files, chats written out to text files, and the ability to reopen a previous session and carry on. Built to understand prompting, persistent context, context windows and token usage properly, rather than through a chat UI.

Self-hosted AI environment

I run a personal Ubuntu server on Hetzner with a self-hosted OpenClaw setup, and use it to experiment with agentic workflows, APIs and scheduled automation — including tracking Amazon listings for a side project. Hands-on with the Linux command line, cron, Tailscale, Cloudflare tunnels, Traefik and Fail2ban.

DataForSEO MCP

An MCP integration I built over the DataForSEO API to pull search trend and keyword data into the same workflows as everything else. Mine end to end, and the most likely candidate for a public repo once it's cleaned up.

Time tracking MCP

An MCP integration for our internal time tracking tool, so hours can be logged and checked in natural language — "add three hours to this project", "how much have I tracked this week". Made available to the wider team, though adoption has been limited.

OneClickDismiss

A Chrome extension that clears all Google Ads recommendations on the page in one click, instead of dismissing them one at a time through a confirmation dialog each. Small, but it saves real minutes across large accounts.

Process notes automation

A personal workflow that pulls together Slack, my notes and calendar context to summarise what I did, what got finished and what's still outstanding. Purely a productivity experiment, but a useful one.

About

I started in paid search and became steadily more interested in the systems behind the work — the APIs, the reporting pipelines, the parts of account management that are the same every week. More recently that's turned into LLMs, MCP and agentic tooling, and into building things that other people in the team actually use.

Today I manage around 10–15 paid media accounts at Platform81, with monthly budgets from £500 to £50,000, while building the workflows above: scheduled search query analysis, automated audits, Merchant Center monitoring and AI-generated client reviews. Managing accounts myself is the point — it's why I can tell the difference between a process that's annoying and a process that's genuinely worth automating, and why I know where a human has to stay in the loop.

Outside work I experiment with LLM APIs, MCP integrations, self-hosted agents and terminal-based AI development, and I'm co-developing a feed management SaaS platform with a friend. I'm currently working through Boot.dev's Linux and command-line material, mostly because I'd rather understand the terminal than rely on AI to hide it from me.
